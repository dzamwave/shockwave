## 1. Назначение и возможности

Локальная система голосовой диктовки без рук для Windows, работающая в фоновом режиме:
1. **Hands-Free активация (Vosk):** Фоновое распознавание кодового слова (*«Мегатрон»*) с околонулевой нагрузкой на CPU.
2. **Системный хоткей:** Нативный Win32 `RegisterHotKey` (по умолчанию `Ctrl + Space`), устойчив ко сну и экрану блокировки.
3. **Распознавание речи (STT):**
   * **Whisper (`large-v3-turbo`):** Локальная инференс-модель для смешанной речи (RU/EN) и терминов программирования.
   * **GigaAM (`gigaam-v3-e2e-rnnt`):** ONNX-модель от Сбера для скоростного распознавания русской речи на CPU.
4. **LLM-нормализация:** Восстановление пунктуации, удаление слов-паразитов, режим генерации AI-промптов (`AI task`), мгновенный перевод на английский (`to EN`) через Gemini Flash Lite или OpenAI API.
5. **Интерфейс:** Плавающий радар-виджет (Dot-Matrix Radar 32×32), тулбар с тумблерами и системный трей.

## 2. Ключевые файлы (`src/` и корень)

* `src/main.py` — Точка входа приложения, инициализация потоков и жизненного цикла.
* `src/audio_engine.py` — Захват звука с микрофона (`sounddevice`), буферизация аудио и фильтрация.
* `src/wake_word.py` — Движок постоянного прослушивания кодового слова на базе Vosk.
* `src/model_manager.py` — Загрузка и управление весами Whisper (`faster-whisper`) и GigaAM (`onnx-asr`).
* `src/llm_normalizer.py` — Обработка распознанного текста через LLM (нормализация, задачи, перевод).
* `src/assistant.py` — Модуль голосового ассистента Windows: Function Calling (open_app, run_command, system_status) через Gemini/OpenAI API.
* `src/tts.py` — Синтез речи (Edge-TTS нейросетевые голоса с SAPI fallback) для голосового подтверждения команд.
* `src/hotkey_manager.py` — Обработка глобальных Win32 горячих клавиш.
* `src/ui.py` — Плавающий оверлей, микропиксельная матрица радара, переключатели режимов.
* `src/glossary.py` — Словарь автозамен узкоспециализированных терминов (`glossary.txt`) с горячей перезагрузкой.
* `src/typer.py` — Автоматический ввод текста и вставка через системный буфер обмена.
* `src/config.py` — Загрузка и валидация настроек из `config.ini`.
* `start.bat` — Скрипт запуска приложения.
* `build.bat` — Сборка портативного standalone EXE через PyInstaller.
