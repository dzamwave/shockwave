## 1. Назначение и возможности

Локальная система голосовой диктовки без рук для Windows, работающая в фоновом режиме:
1. **Hands-Free активация (Vosk):** Фоновое распознавание кодового слова. В `config.ini` сейчас это *«шоквейв»*; если ключа нет, код берёт *«мега»*.
2. **Системный хоткей:** Нативный Win32 `RegisterHotKey` (по умолчанию `Ctrl + Space`), устойчив ко сну и экрану блокировки.
3. **Распознавание речи (STT):**
   * **Whisper (`large-v3-turbo`):** Локальная инференс-модель для смешанной речи (RU/EN) и терминов программирования.
   * **GigaAM (`gigaam-v3-e2e-rnnt`):** ONNX-модель от Сбера для скоростного распознавания русской речи на CPU.
4. **LLM-обработка:** Нормализация пунктуации (`LLM norm`), заготовка идеи (`Idea`), промпт для AI (`AI task`) и перевод на английский (`to EN`). Если включены нормализация, Idea и `to EN`, запросы идут по очереди: нормализация, затем идея, затем перевод. Слова-паразиты убирает промпт `AI task`, не обычная нормализация. Адрес, ключ и модель читаются из `LLM_ENDPOINT`, `LLM_API_KEY`, `LLM_MODEL`.
5. **Интерфейс:** Плавающий радар-виджет (Dot-Matrix Radar 32×32), тулбар с тумблерами и системный трей.

## 2. Ключевые файлы (`src/` и корень)

* `src/launcher.py` — Запуск приложения. Настройки из терминала не меняются: они читаются из `config.ini`. Флаги `--widget` и `--silent` сразу показывают виджет.
* `src/main.py` — Сборка приложения: запись, очередь интерфейса, словарь, LLM, буфер обмена, выход.
* `src/audio_engine.py` — Захват звука с микрофона (`sounddevice`), буфер и распознавание Whisper или GigaAM.
* `src/wake_word.py` — Кодовое слово Vosk. Звук складывается в очередь, распознавание идёт в своём потоке.
* `src/model_manager.py` — Проверка и скачивание весов Whisper и GigaAM перед стартом.
* `src/llm_normalizer.py` — Запросы к LLM: нормализация, идея, задача, перевод.
* `src/hotkey_manager.py` — Глобальная клавиша Win32 `RegisterHotKey`, запасной вариант — библиотека `keyboard`.
* `src/ui.py` — Плавающий оверлей, радар и переключатели режимов.
* `src/tray_manager.py` — Иконка у часов, показ и скрытие консоли.
* `src/glossary.py` — Автозамены из `glossary.txt` с перечитыванием при изменении файла.
* `src/typer.py` — Кладёт готовый текст в буфер обмена. Клавиши не нажимает.
* `src/config.py` — Чтение `config.ini`, `.env` и промптов, путь к файлам сборки.
* `src/single_instance.py` — Один запущенный процесс через именованный mutex Windows.
* `start.bat` — Запуск приложения из виртуального окружения.
* `build.bat` — Сборка EXE через PyInstaller.

## 3. Команды запуска и сборки

```bash
# Запуск
start.bat
# или
python src/launcher.py

# Сразу виджет, без приветствия в терминале
python src/launcher.py --widget

# Сборка дистрибутива
build.bat
```

## 4. Инварианты проекта

1. **Разделение конфигов:** рабочий `config/config.ini` скрыт от Git. В репозитории лежит `config/config.example.ini`: те же настройки, но `endpoint`, `model` и `api_key` пустые. Пустое поле `[LLM]` берётся из `config/.env`. Тексты промптов — в `config/prompts/*.md`.
2. **Буфер обмена:** `typer.py` только копирует текст. Активное окно не переключается, потому что программа не эмулирует нажатия клавиш.
3. **Ответы агента:** На русском языке, лаконично.
