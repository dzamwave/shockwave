# Shockwave — Руководство по установке и использованию

---

## 🚀 Вариант 1. Быстрый старт (Без установки Python)

*Этот вариант подходит для большинства пользователей. Python и дополнительные программы устанавливать не требуется.*

1. **Скачайте готовый архив:**  
   Перейдите на страницу **[GitHub Releases](https://github.com/mariobr0/shockwave/releases)** и скачайте **`Shockwave-v0.9.3-Portable.zip`**.
2. **Распакуйте архив** в любую удобную папку (например, `C:\Shockwave`).
3. **Настройте `config.ini`** в папке `config`: движок, кодовое слово, горячую клавишу и секцию `[LLM]`.
4. **Запустите `Shockwave.exe`**. Если выбранной модели ещё нет, программа предложит скачать именно её и не будет менять настройки. Затем панель свернётся в системный трей (возле часов), а на экране появится фиолетовый виджет.
5. Нажмите **`Ctrl + Space`** в любой программе, чтобы начать запись, и повторно — чтобы её завершить. Надиктуйте текст и вставьте результат (`Ctrl + V`).

## 🛠️ Вариант 2. Сборка из исходного кода

Если вы хотите запустить проект из исходников или модифицировать код под себя:

### 1. Требования
* Windows 10 / 11
* Python 3.10 или новее (при установке обязательно поставьте галочку **Add python.exe to PATH**)
* Git (опционально)

### 2. Клонирование и установка зависимостей
```bat
git clone https://github.com/mariobr0/shockwave.git
cd shockwave

python -m venv venv
call venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Сборка `.exe` или прямой запуск
* **Сборка бинарника:** запустите **`build.bat`**. Скрипт создаст автономный `dist\Shockwave.exe` и два ярлыка:
  1. **`Shockwave.lnk`** — Панель управления с автоматическим сворачиванием в трей.
  2. **`Shockwave (Виджет).lnk`** — Прямой тихий запуск сразу фиолетового виджета.
* **Прямой запуск через Python:** запустите **`start.bat`**.

## ⚙️ Настройка LLM (Нейросеть для пунктуации)

| Провайдер | Эндпоинт (`LLM_ENDPOINT`) | Модель (`LLM_MODEL`) | Где получить ключ |
| :--- | :--- | :--- | :--- |
| **Google AI Studio** | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` | `gemini-2.5-flash-lite` | [aistudio.google.com](https://aistudio.google.com/) |
| **OpenAI** | `https://api.openai.com/v1/chat/completions` | `gpt-4o-mini` | [platform.openai.com](https://platform.openai.com/) |
| **OpenRouter** | `https://openrouter.ai/api/v1/chat/completions` | `google/gemini-2.5-flash-lite` | [openrouter.ai](https://openrouter.ai/) |
| **Ollama (Локально)** | `http://localhost:11434/v1/chat/completions` | `qwen2.5:7b` | Не требуется (оффлайн) |

Для внешних LLM-серверов требуется HTTPS. HTTP разрешён только для `localhost` и адресов обратной связи (`127.0.0.1`, `::1`) на этом компьютере; HTTP-адрес другого компьютера в локальной сети не подходит. Автоматические перенаправления отключены: указывайте конечный адрес API. Если адрес отклонён, исходная диктовка сохраняется.

Если обработка LLM не удалась, ответ пустой или обрезан, в буфер копируется текст до обработки LLM, а виджет показывает «LLM: исходный сохранён» вместо `ready`. Готовым считается непустой текст с подтверждением завершения (`finish_reason: stop`); сервисы без этого подтверждения тоже возвращают исходную диктовку. При ошибке словаря сохраняется текст до замен, дальнейшая обработка LLM пропускается. Сохранение здесь означает копирование в буфер обмена, а не создание отдельного файла.

## 🎛️ Настройка через `config.ini`

Все настройки хранятся в `config/config.ini` (шаблон — `config/config.example.ini`, сам рабочий файл скрыт от Git). При запуске терминал их не меняет. Пустое поле секции `[LLM]` берётся из `.env`. Старые значения распознавания из `.env` используются, только если соответствующего параметра нет в `config.ini`.

* `[Recording] hotkey = ctrl+space` — системная комбинация клавиш.
* `[Recognition] whisper_language = ru` — язык Whisper (`ru`, `auto`, `en` и др.).
* `[Recognition] gigaam_quantization = int8` — сжатая модель; `float32` — полная версия. Для выбранной версии нужны соответствующие файлы модели.
* `[Widget] position = bottom-left` — начальная позиция виджета.
* `[Widget] opacity = 0.80` — прозрачность плашки.
* `[Sound] alert_sound = true` — звуковые оповещения.

Название секции в квадратных скобках указывается на отдельной строке, а её параметры — ниже, как в шаблоне. Если папка Vosk пустая или содержит только `.gitkeep`, приложение установит модель автоматически. Если в ней уже есть другие файлы, но модель неполная, приложение сообщит об этом и сохранит файлы.

#### Выбор горячих клавиш:
* ✅ **Рекомендуемые:** `ctrl+space`, `alt+space`, `f9`, `f8`, `f10`, `pause`.
* ⚠️ **Не рекомендуемые:** `f12` (зарезервирована Windows Debugger), `f11` (полный экран), `f5` (обновление).

## 🖱️ Управление виджетом и Трей

* **Левая ручка (`⋮⋮`):** Зажмите левой кнопкой мыши для свободного перемещения плашки по экрану.
* **Глаз Shockwave (🟡):** Кликабельная кнопка включения/выключения записи с визуальной индикацией (горит жёлтым при работе).
* **Чекбокс `LLM norm`:** Включение/выключение нормализации текста через нейросеть.
* **Чекбокс `alert`:** Включение/выключение звукового сигнала и стартовой фразы.
* **Иконка в трее (возле часов):** Двойной клик разворачивает / скрывает консоль; правый клик открывает меню управления.
* **Защита от дубликатов:** Повторный запуск программы автоматически предотвращается без лишней траты ресурсов.
* **Остановка кодовым словом:** Аудио сохраняется целиком. Удаляется только распознанное кодовое слово в конце текста. Если распознавание не нашло его в конце, текст сохраняется без удаления, поэтому кодовое слово может остаться в результате.
* **Кнопка `×`:** Закрытие программы.
