# Shockwave — Руководство по установке и использованию

---

## 🚀 Вариант 1. Быстрый старт (Без установки Python)

*Этот вариант подходит для большинства пользователей. Python и дополнительные программы устанавливать не требуется.*

1. **Скачайте готовый архив:**
   Перейдите на страницу **[GitHub Releases](https://github.com/dzamwave/shockwave/releases)** и скачайте последнюю версию **`Shockwave-v1.1.1-Windows-x64.zip`**.
2. **Распакуйте архив** в любую удобную папку (например, `C:\Shockwave`).
3. **Настройте `config.ini`** в папке `config`: движок, кодовое слово, горячую клавишу и секцию `[LLM]`.
4. **Запустите `Shockwave.exe`**. Если выбранной модели ещё нет, программа предложит скачать именно её и не будет менять настройки. Затем панель свернётся в системный трей (возле часов), а на экране появится фиолетовый виджет.
5. Нажмите **`Ctrl + Space`** в любой программе, чтобы начать запись, и повторно — чтобы её завершить. Надиктуйте текст и вставьте результат (`Ctrl + V`).

## 🛠️ Вариант 2. Сборка из исходного кода

Если вы хотите запустить проект из исходников или модифицировать код под себя:

### 1. Требования
* Windows 10 / 11
* Python 3.10 или новее (при установке обязательно поставьте галочку **Add python.exe to PATH**)
* Git (опционально)

### 2. Клонирование и установка зависимостей
```bat
git clone https://github.com/dzamwave/shockwave.git
cd shockwave

python -m venv venv
call venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Сборка `.exe` или прямой запуск
* **Сборка бинарника:** запустите **`build.bat`**. Скрипт создаст автономный `dist\Shockwave.exe` и ярлык на рабочем столе:
  * **`Shockwave.lnk`** — Запуск с консолью и автоматическим сворачиванием в трей.
* **Прямой запуск через Python:** запустите **`start.bat`** или `python src/launcher.py`.

## ⚙️ Настройка LLM (Нейросеть для обработки текста)

| Провайдер | Эндпоинт | Модель | Где получить ключ |
| :--- | :--- | :--- | :--- |
| **Google AI Studio** | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` | `gemini-2.5-flash` | [aistudio.google.com](https://aistudio.google.com/) |
| **OpenAI** | `https://api.openai.com/v1/chat/completions` | `gpt-4o-mini` | [platform.openai.com](https://platform.openai.com/) |
| **OpenRouter** | `https://openrouter.ai/api/v1/chat/completions` | `google/gemini-2.5-flash` | [openrouter.ai](https://openrouter.ai/) |
| **Ollama (Локально)** | `http://localhost:11434/v1/chat/completions` | `qwen2.5:7b` | Не требуется (оффлайн) |

Для внешних LLM-серверов требуется HTTPS. HTTP разрешён только для `localhost` и адресов обратной связи (`127.0.0.1`, `::1`) на этом компьютере; HTTP-адрес другого компьютера в локальной сети не подходит. Автоматические перенаправления отключены: указывайте конечный адрес API. Если адрес отклонён, исходная диктовка сохраняется.

Если обработка LLM не удалась, ответ пустой или обрезан, в буфер копируется текст до обработки LLM, а виджет показывает «LLM: исходный сохранён» вместо `ready`. Готовым считается непустой текст с подтверждением завершения (`finish_reason: stop`); сервисы без этого подтверждения тоже возвращают исходную диктовку. При ошибке словаря сохраняется текст до замен, дальнейшая обработка LLM пропускается. «Сохранено» здесь означает копирование в буфер обмена, а не создание отдельного файла.

## 🎛️ Настройка через `config.ini`

Все настройки хранятся в `config/config.ini` (шаблон — `config/config.example.ini`, сам рабочий файл скрыт от Git). При запуске терминал их не меняет. Пустое поле секции `[LLM]` берётся из `config/.env`.

**Основные параметры:**

* `[Recording] hotkey = ctrl+space` — системная комбинация клавиш.
* `[Recording] max_record_seconds = 180` — лимит длительности записи (секунды), после которого она завершается автоматически.
* `[Recording] warn_record_seconds = 150` — порог, после которого радар переходит в режим красного мигания.
* `[Recognition] engine = gigaam_model` — движок STT: `whisper_model` или `gigaam_model`.
* `[Recognition] whisper_language = ru` — язык Whisper (`ru`, `auto`, `en` и др.).
* `[Recognition] gigaam_quantization = int8` — сжатая модель; `float32` — полная версия.
* `[Recognition] model_idle_timeout = 300` — секунды простоя до выгрузки STT-модели из памяти (0 — не выгружать).
* `[Wake] wake = true` — включить/выключить прослушивание кодового слова.
* `[Wake] wake_word = мега` — кодовое слово для голосовой активации.
* `[Text] llm_norm = false` — нормализация пунктуации.
* `[Text] ai_task = false` — генерация структурированного промпта для AI.
* `[Text] to_en = false` — перевод на английский.
* `[Text] idea = false` — режим структурирования идеи.
* `[Text] clip_prepend = false` — вставка надиктованного текста перед содержимым буфера.
* `[Widget] position = bottom-right` — начальная позиция виджета (`bottom-right`, `bottom-left`, `top-center`).
* `[Widget] opacity = 0.85` — прозрачность плашки (0.0–1.0).
* `[Sound] startup_sound = true` — голосовое приветствие Мегатрона при запуске.
* `[Sound] alert_sound = true` — звуковой сигнал готовности текста.
* `[Console] language = ru` — язык сообщений в терминале (`ru` / `en`).

Название секции в квадратных скобках указывается на отдельной строке, а её параметры — ниже, как в шаблоне.

#### Выбор горячих клавиш:
* ✅ **Рекомендуемые:** `ctrl+space`, `alt+space`, `f9`, `f8`, `f10`, `pause`.
* ⚠️ **Не рекомендуемые:** `f12` (зарезервирована Windows Debugger), `f11` (полный экран), `f5` (обновление).

#### Настройка системных промптов:
Все пять промптов можно свободно редактировать в папке `config/prompts/`:
`normalization.md`, `translate_en.md`, `ai_task.md`, `ai_task_en.md`, `idea.md`.
Отсутствующие файлы создаются автоматически с разумными значениями по умолчанию при первом запуске.
Промпт также можно задать напрямую в `config.ini` в секции `[Prompts]` — он будет иметь приоритет над файлом.

## 🖱️ Управление виджетом и трей

Плавающий виджет содержит два ряда переключателей:

**Ряд 1 (режимы обработки текста):**
* **`LLM norm`** — нормализация пунктуации и технической терминологии через LLM.
* **`AI task`** — превращает надиктованную речь в структурированный промпт для AI-ассистента. Взаимоисключает `Idea`.
* **`to EN`** — перевод результата на английский. Вместе с `AI task` → один запрос, генерирующий английский промпт. Вместе с `Idea` → перевод после структурирования.
* **`Idea`** — структурирует свободный монолог в заготовку для публикации: главная мысль, собранный текст и направления для развития. Взаимоисключает `AI task`.

**Ряд 2 (запись и буфер):**
* **`wake`** — включить/выключить фоновое прослушивание кодового слова (Vosk).
* **`alert`** — воспроизводить звуковой сигнал готовности текста (при активации голосом и по завершении обработки).
* **`clip+`** — добавить надиктованный текст перед содержимым буфера обмена через двойной перенос строки.

**Остальные элементы:**
* **Кнопка-радар (🟡):** Клик для старта/остановки записи. Во время записи отображает анимацию вращающегося луча; при превышении `warn_record_seconds` переходит в режим красного мигания.
* **Обратный отсчёт:** Появляется рядом с кнопкой `cancel` во время записи и показывает оставшееся время до автостопа.
* **Ссылка `cancel`:** Мгновенно прерывает текущую запись без транскрипции.
* **Кнопка `×`:** Закрытие программы.
* **Перетаскивание:** Нажмите и удерживайте левую кнопку мыши в любом месте фона виджета, чтобы переместить его по экрану.
* **Иконка в трее (возле часов):** Правый клик открывает меню (показать виджет / выход).
* **Защита от дубликатов:** Повторный запуск программы автоматически предотвращается.
* **Остановка кодовым словом:** Аудио сохраняется целиком до сигнала остановки. Удаляется только распознанное кодовое слово в конце расшифровки. Если оно не найдено в конце — текст сохраняется без изменений.
